# Device identity

Manufacturer: **Tunnlix**. Product: **Key**.

The onboard Key model AAGUID is `fa024a59-a2a6-41d9-bd40-ed6a78915bca`. This identifier is stable
across firmware revisions and shared by devices of this model; it is not a device
serial number or a claim of FIDO certification. Existing credentials keep their
original registration data. Attestation `none` can expose a zero AAGUID by design.

USB VID/PID `1209:0001` remains a nonunique private-test pair. A public PID
application is deferred. Do not distribute hardware
with this private-test identity.
